# 👋 About Me

Backend and Kotlin Multiplatform engineer (B.Tech CSE, 2027) focused on **reliable software**: well-tested, stable in CI and safe with user data. I design **Spring Boot** APIs and the **Compose Multiplatform** clients that consume them.

- 🌍 **Google Summer of Code 2026, Kiwix Android (1M+ installs):** raised test coverage from 60.48% to 81.36% across 22 merged PRs, eliminated flaky CI, and fixed data-loss and race-condition bugs
- ⚙️ **Glow:** Spring Boot backend with JWT auth, atomic transactional checkout, N+1 fixes and Redis caching, deployed on AWS, with a Compose Multiplatform client for Android, iOS and Desktop
- 📦 **OTPVerificationKMP:** Kotlin Multiplatform SDK published to Maven Central
- 🎯 Open to entry-level **Backend** and **Android** roles
